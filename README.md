
Crypto Analysis Dashboard
About the Project
This project is a Crypto Analysis Dashboard created using Microsoft Excel.The purpose of this project is to analyze cryptocurrency data and create useful insights using prices, trading volume, market capitalization, circulating supply, and price changes.The project contains 5 different analyses with interactive dashboards, KPIs, slicers, charts, lookup functions, and data validation.

Tools Used
Microsoft Excel
Lookup Functions
Data Validation
Pivot Tables
Slicers
KPIs
Charts
Data Cleaning
